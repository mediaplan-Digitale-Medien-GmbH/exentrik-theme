# Exentrik (Schompi Trading)

Shopify-Theme für **exentrik.com** (Schompi Trading), gestartet aus dem mediaplan Shopify Theme-Rohling.

## Git / Shopify

- Repo-Root = Theme-Root (für GitHub-Integration in Shopify)
- Branches: `main` (Live), `staging` (Preview)

## Start

1. In Shopify: Online Store → Themes → Theme library → Add theme → Connect from GitHub → dieses Repo, Branch `staging` oder `main`.
2. Logo, Farben, Favicon, Schriften und Socials im Theme-Editor setzen.
3. Startseite und Menüs befüllen.
